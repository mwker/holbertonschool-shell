# Shell, init files, variables and expansions


Ce projet contient des scripts Bash pour apprendre les fichiers d'initialisation du shell, les variables, les expansions, l'arithmétique et les alias.

## Scripts

- `0-alias` : crée un alias nommé `ls` dont la valeur est `rm -f *`.
- `1-hello_you` : affiche `hello` suivi du nom de l'utilisateur Linux courant.
- `2-path` : ajoute `/action` à la fin du `PATH`, pour que ce soit le dernier répertoire dans lequel le shell cherche un programme.
- `3-paths` : compte le nombre de répertoires présents dans le `PATH`.
- `4-global_variables` : liste les variables d'environnement.
- `5-local_variables` : liste toutes les variables locales, les variables d'environnement et les fonctions.
- `6-create_local_variable` : crée une variable locale nommée `BEST` avec la valeur `School`.
- `7-create_global_variable` : crée une variable globale nommée `BEST` avec la valeur `School`.
- `8-true_knowledge` : affiche le résultat de l'addition de 128 et de la valeur de la variable d'environnement `TRUEKNOWLEDGE`.
- `9-divide_and_rule` : affiche le résultat de la division de `POWER` par `DIVIDE`.
- `10-love_exponent_breath` : affiche le résultat de `BREATH` à la puissance `LOVE`.
- `11-binary_to_decimal` : convertit en base 10 le nombre binaire stocké dans la variable d'environnement `BINARY`.
- `12-combinations` : affiche toutes les combinaisons possibles de deux lettres minuscules, sauf `oo`, triées par ordre alphabétique.
- `13-print_float` : affiche le nombre stocké dans la variable d'environnement `NUM` avec deux décimales.
- `14-decimal_to_hexadecimal` : convertit en base 16 le nombre stocké dans la variable d'environnement `DECIMAL`.
