# Shell, basics


Ce projet contient des scripts Bash pour apprendre les bases du shell.

## Scripts

- `0-current_working_directory` : affiche le chemin absolu du répertoire de travail actuel.
- `1-listit` : affiche le contenu du répertoire courant.
- `2-bring_me_home` : change le répertoire de travail pour le répertoire personnel de l'utilisateur.
- `3-listfiles` : affiche le contenu du répertoire courant au format long.
- `4-listmorefiles` : affiche le contenu du répertoire courant au format long, y compris les fichiers cachés.
- `5-listfilesdigitonly` : affiche le contenu du répertoire courant au format long, avec les fichiers cachés et les ID utilisateur et groupe sous forme numérique.
- `6-firstdirectory` : crée un répertoire nommé `my_first_directory` dans `/tmp/`.
- `7-movethatfile` : déplace le fichier `betty` de `/tmp/` vers `/tmp/my_first_directory`.
- `8-firstdelete` : supprime le fichier `betty` qui se trouve dans `/tmp/my_first_directory`.
- `9-firstdirdeletion` : supprime le répertoire `my_first_directory` qui se trouve dans `/tmp`.
- `10-back` : change le répertoire de travail pour le répertoire précédent.
- `11-lists` : liste au format long tous les fichiers, y compris les fichiers cachés, du répertoire courant, du répertoire parent et de `/boot`.
- `12-file_type` : affiche le type du fichier `iamafile` situé dans `/tmp`.
- `13-symbolic_link` : crée dans le répertoire courant un lien symbolique nommé `__ls__` vers `/bin/ls`.
